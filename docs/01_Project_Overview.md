# Project Overview

## Introduction

CloudTask Pro is a cloud-native task and project management platform inspired by modern SaaS products such as Linear, Notion, Jira, and Trello.

The application enables users to create projects, organize tasks, monitor progress, collaborate with team members, and visualize productivity through analytics dashboards.

Beyond application functionality, CloudTask Pro is designed as a learning project focused on production-grade cloud engineering.

---

# Objectives

The primary objectives of this project are:

* Design a scalable cloud architecture.
* Build a secure REST API.
* Deploy infrastructure on AWS.
* Automate deployments using CI/CD.
* Provision infrastructure using Terraform.
* Implement monitoring and logging.
* Apply cloud security best practices.
* Document every engineering decision.

# Project Scope

The project intentionally covers multiple areas of software engineering, including frontend development, backend development, cloud infrastructure, DevOps practices, monitoring, and security.

The goal is not simply to deploy an application, but to understand how modern production systems are designed and operated.
